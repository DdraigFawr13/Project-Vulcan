# build

Plans and built parts (P3.1, P3.2): walls, floors, doors and stairs in wood and stone, a tile each.

- **Public API:** `index.ts`: `buildSystem`, `BUILD_TABLES`, `plansOf(world)`, `planAt(world, x, y, z = 0)`, `partOf(content, id)`, `planPart(content, plan)`, `stillNeeded(content, plan)` (material still to bring; 0 once all is in or for a part to come down), `finishPlan(ctx, plan, cause)` (sets the part on the map: `setBuilt` for a wall, floor or door, `cutStairsAt` for a stair, which reaches the level below), `takeDownPlan(ctx, plan, cause)` (clears it from the map, removes the row and returns the material to lay back: all of it for a built part, what was brought for a plan).
- **Parts:** content `buildings.json`: the build `job` (jobs.json, building skill), the skill dial `skilled`, `downShare` (per cent of a part's minutes to take it down) and one entry per part: kind (`wall` blocks the way, `door` and `floor` do not, `stair` cuts a way down), material (an item), cost, minutes and art. A built part is `map.built` (1 + its index); a stair is a tile kind instead, so stairs keep working as before.
- **Placing (test mode only until P3.7, V-041, V-049):** `placeBuilding {part, x, y}` puts a plan on a buildable surface tile with no feature, plan, built part or store on it (and, for all but a floor, nothing lying there); otherwise `command.refused` with the reason. A plan of a good the colony keeps none of raises that good's stock level to its first non-zero level (goods `raiseStock`, a `goods.stockRaised` line citing the plan). `deconstruct {x, y}` drops a plan nothing was brought for at once (`build.dropped`), else orders the plan or built part down (`build.downOrdered`; state `down`); a cut stair stays.
- **Work:** done by people (`src/engine/people/build.ts`): nobody is ordered. A builder takes up the nearest free plan, fetches its material from wherever it lies (the store before ground at the same distance), brings it, then builds from beside the tile; a part finishes only when nobody stands on its tile, and anything lying on a wall or door tile is moved beside the builder first. Plans whose material nobody can reach share one `build.waiting` alert per material until some is brought.
- **Checks:** each hour, while a plan waits and no living person meets the build job's requirements, one `build.nobody` alert (system state `nobody`, cleared when that changes).
- **Events:** `build.planned`, `build.dropped`, `build.downOrdered` (cite the order), `build.nobody` (cites the plan); from people: `work.tookUpBuilding` (cites the plan and the builder's priority if set), `build.waiting` (cites the plan), `build.built` (cites taking it up; a stair's `map.stairsCut` cites it), `build.takenDown` (cites taking it up and the order).
- **State owned:** table `plan` (part, x, y, z, have, work, state `plan` / `built` / `down`, line, done, waited); system state `nobody`. `map.built` is written only through map `setBuilt`.
- **Invariants:** one plan row a tile; a row in state `built` matches `map.built` (or a stair tile); surface only for now.
- **Tests:** `build.test.ts` (a planned stone wall is built from quarried, hauled stone with only the placing orders, its tiles block the way and its lines lead back to the plan; taking it down gives the stone back; refusals; a wooden stair reaches level 1; every command is an indirect lever or a test-mode tool).
