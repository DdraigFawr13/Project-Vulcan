# sim

The tick loop: runs each system when it is due, in a fixed order, and applies the player's levers on the tick they are stamped for.

- **Public API:** `index.ts`: `createSim(content, systems, recentDays?)` (checks ids, command kinds and entity kinds are unique, and that every type a system lists in `emits` has a template; gathers the systems' `tables` into `sim.tables`), `createWorld(sim, seed)` (writes `world.begun`), `submitCommand(world, {tick, kind, data})` (returns the stamped command), `step(world, sim, ticks, stopAt?)` (returns the recent lines written; with `stopAt`, a set of event types or a test such as `sim.notable`, it stops after the first tick that writes one, for P2.7's skip ahead), `replay(sim, seed, commandLog, tick)`; types `Sim`, `System`, `SystemContext`, `Cadence`.
- **Events:** emits `world.begun`, `command.applied` (the cause a handler cites) and `command.refused` (no system handles the kind).
- **State owned:** `tick`, `nextCommandSeq`, `commandLog`, `pending`, `begunEvent`; `world.systems[id]` is created from each system's `initialState` and then owned by that system; a system's optional `init` runs once in `createWorld`, after `world.begun`, in list order (the map lays out `world.map` there).
- **Tick order:** `tick += 1`; apply every pending command due, by tick then seq; then each system whose cadence (`minute`, `hour`, `day`, `month`) falls on the tick, in list order; at midnight, seal old days (`src/engine/log/MODULE.md`), keeping as stubs the lines cited by tiles, by each system's `refs` (state keys holding ledger ids) and by entity `event` fields.
- **Invariants:** a command applies on `max(asked, tick + 1)`, never in the past and never dropped; a tick that is not a whole number throws. A kind no system owns (own keys only) is logged as refused. Handlers check their command's data before changing state, since a throw inside one stops the tick. Seed plus `commandLog` replays the same world.
- **Tests:** `src/engine/engine.test.ts` (determinism, replay, late and unknown levers).
