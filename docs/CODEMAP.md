# Code map

Generated by `npm run codemap`; don't edit. Read a module's `MODULE.md` before its code.

- `src/content/` Game data: the forked Story Generator raws plus Vulcan's own tiles, recipes, jobs and laws, with validators. Exports: Content, content, contentHash, hashContent, rawContent, validateContent.
- `src/engine/` The pure, deterministic simulation: state, systems and the event log. Exports: * from ./core/index.ts, * from ./log/index.ts, CHUNK, Cadence, SYSTEMS, Sim, System, SystemContext, calendarSystem, chunkTiles, chunksAcross, chunksDown, createSim, createWorld, mapSystem, replay, setTile, step, submitCommand.
- `src/engine/calendar/` The valley's calendar in the ledger: a line for each new day, month and season. Exports: calendarSystem.
- `src/engine/core/` The engine's shared vocabulary: world and event types, the named RNG streams, string hashes and the game clock. Exports: * from ./types.ts, Clock, RngState, RngStream, START_TICK, TICKS_PER_DAY, TICKS_PER_HOUR, clockAt, deriveStreamState, hash128, hashString, nextUint32, streamFor, ticksPerMonth.
- `src/engine/log/` The ledger: writes every event with its causes, refuses ones content has no text for, and renders and exports them. Exports: EventFields, Templates, emit, renderEvent, templatesOf, toNdjson.
- `src/engine/map/` The valley's ground: every surface tile and what it is made of. Exports: CHUNK, chunkTiles, chunksAcross, chunksDown, mapSystem, setTile.
- `src/engine/sim/` The tick loop: runs each system when it is due, in a fixed order, and applies the player's levers on the tick they are stamped for. Exports: Cadence, Sim, System, SystemContext, createSim, createWorld, replay, step, submitCommand.
- `src/persist/` Saves in IndexedDB and NDJSON export, on the main thread. Empty until P0.5.
- `src/render/` Phaser scenes, tilemap layers, sprites and camera. Reads snapshots from the worker and never changes game state. Exports: Hover, Renderer, ZOOMS, startRenderer.
- `src/ui/` The page entry, panels, inspector, ledger browser and controls. Sends commands to the worker and shows snapshots and events.
- `src/worker/` The Web Worker that owns the engine, runs the tick loop and answers the main thread. Exports: ChunkView, ClockView, FromWorker, Speed, TICKS_PER_SECOND, ToWorker, spawnSimWorker.
