# Code map

Generated by `npm run codemap`; don't edit. Read a module's `MODULE.md` before its code.

- `src/content/` Game data: the forked Story Generator raws plus Vulcan's own tiles, recipes, jobs and laws, with validators. Exports: Content, content, contentHash, hashContent, rawContent, validateContent.
- `src/engine/` The pure, deterministic simulation: state, systems and the event log. Exports: * from ./core/index.ts, * from ./entity/index.ts, * from ./log/index.ts, CHUNK, Cadence, Home, PEOPLE_TABLES, Person, Region, RegionNeighbour, RegionSite, RegionValley, SYSTEMS, Sim, System, SystemContext, auraAt, calendarSystem, chunkTiles, chunksAcross, chunksDown, createSim, createWorld, drawBand, isFrozen, layerOf, makeRegion, mapSystem, peopleSystem, regionSystem, replay, setTile, siteOf, step, submitCommand, tileTemperature, tradeOf, valleyOf, weatherSystem, weatherWords.
- `src/engine/calendar/` The valley's calendar in the ledger: a line for each new day, month and season. Exports: calendarSystem.
- `src/engine/core/` The engine's shared vocabulary: world and event types, the named RNG streams, string hashes and the game clock. Exports: * from ./climate.ts, * from ./people.ts, * from ./region.ts, * from ./types.ts, Clock, RngState, RngStream, START_TICK, TICKS_PER_DAY, TICKS_PER_HOUR, clockAt, deriveStreamState, hash128, hashString, nextUint32, streamFor, ticksPerMonth.
- `src/engine/entity/` Entity tables: every person, item and later creature as a row of its kind, with one id counter for all kinds. Exports: FieldType, Schemas, TableSchema, addEntity, citedByEntities, entityOf, removeEntity, tablesProblem.
- `src/engine/log/` The ledger: writes every event with its causes, refuses ones content has no text for, renders and exports them, and seals old days. Exports: Cause, EventFields, RECENT_DAYS, Templates, allLines, emit, findEvent, recordOf, renderEvent, sealDays, templatesOf, toNdjson, whyOf.
- `src/engine/map/` The valley's ground: every surface tile and what it is made of, and the four levels below. Exports: CHUNK, auraAt, chunkTiles, chunksAcross, chunksDown, layerOf, mapSystem, raiseChunk, setTile.
- `src/engine/people/` The band and the people of the valley: who they are (P2.1); needs, paths and work follow in later milestones. Exports: Home, PEOPLE_TABLES, Person, drawBand, peopleSystem, tradeOf.
- `src/engine/region/` The region around the valley (P1.5's screen; since P1.6 a window of the seed's Story Generator world, DECISIONS V-031): its named neighbours and the three valleys on offer. Exports: Region, RegionCell, RegionNeighbour, RegionRange, RegionSite, RegionValley, makeRegion, regionSystem, siteOf, valleyOf.
- `src/engine/sim/` The tick loop: runs each system when it is due, in a fixed order, and applies the player's levers on the tick they are stamped for. Exports: Cadence, Sim, System, SystemContext, createSim, createWorld, replay, step, submitCommand.
- `src/engine/weather/` Seasons and daily weather over the valley, the temperature of every surface tile, and ice on still water. Exports: isFrozen, tileTemperature, weatherSystem, weatherWords.
- `src/persist/` Saves in IndexedDB and the ledger download, on the main thread. Exports: AUTOSAVE_ID, RESCUE_ID, SaveMeta, SaveStore, download, gzip, openSaves.
- `src/render/` Phaser scenes, tilemap layers, sprites and camera. Reads snapshots from the worker and never changes game state. Exports: Hover, Renderer, startRenderer.
- `src/ui/` The page entry, panels, inspector, ledger browser and controls. Sends commands to the worker and shows snapshots and events.
- `src/worker/` The Web Worker that owns the engine, runs the tick loop and answers the main thread. Exports: AuraView, ChunkView, ClockView, FromWorker, LedgerLine, RegionView, SAVE_VERSION, SaveFile, Speed, TICKS_PER_SECOND, TileView, TimingView, ToWorker, ValleyPreview, WeatherView, spawnSimWorker.
